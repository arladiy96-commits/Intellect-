# Мой ИИ

Android-приложение на Flutter для локальных моделей Qwen, памяти и ИИ-агентов.

## Сборка через GitHub

1. **Actions → Flutter Bootstrap → Run workflow**: создаёт проект и сохраняет в `main`.
2. **Actions → Build APK → Run workflow**: собирает APK и публикует в **Releases**.

Оба workflow запускаются **только вручную**. GitHub Actions Artifacts не используются.

## Текущее состояние

Первая версия — компилируемый UI-каркас. Общение с моделью НЕ подключено;
чтобы запустить Qwen без Termux, потребуется последующее внедрение llama.cpp в Android.

Содержимое `docs/` — план архитектуры; файлы GGUF и ключи подписи в Git не добавлять.

## Подпись APK

Пока используется тестовая подпись Flutter-шаблона. При сборке на другом
GitHub-runner подпись может отличаться, и обновление приложения поверх старого APK
не установится. Перед регулярным использованием нужно настроить постоянный
ключ подписи через GitHub Secrets.
