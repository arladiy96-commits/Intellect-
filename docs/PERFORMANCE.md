# Производительность «Бабуина» (первый измеряемый этап)

- Для POCO X8 Pro Max (MediaTek Dimensity 9500s / Armv9) сборка GGML CPU использует ARMv8.2 dotprod и FP16; GPU и Vulkan намеренно остаются выключенными.
- В «Модели» можно выбрать 4, 6 или 8 CPU-потоков **после выгрузки модели**; настройка сохраняется на телефоне и применяется при следующей загрузке GGUF.
- После каждого завершённого ответа выводятся фактические **токены/с**, время подготовки запроса и общее время. Это диагностические показатели, а не гарантированная прибавка скорости.
- Для корректного сравнения создайте новый пустой чат и задайте один и тот же вопрос. Сравните 4, 6, 8 потоков для **каждой модели отдельно**, давая телефону остыть между тестами.
- Оставляем llama.cpp/Termux независимыми; Qwen по-прежнему запускается внутри приложения.
- Последний этап ускорения (не входит в это обновление): исследование GPU/Vulkan и KV-cache; оба требуют отдельной проверки на устройстве.
- Для сохранения моделей и чатов устанавливайте обновлённый APK поверх старого, с тем же постоянным ключом подписи.
