# Нативная Qwen на Android — тестовая интеграция

Структура: Flutter UI → MethodChannel/EventChannel → Kotlin worker → JNI C++ → llama.cpp CPU.

Сборка: **Actions → Build APK → Run workflow**. Bootstrap повторно НЕ запускать.
GitHub Actions скачивает исходный код llama.cpp и собирает библиотеку в APK.
GGUF нельзя вкладывать в репозиторий/APK (несколько гигабайт).

На телефоне:

1. Скопировать GGUF из Termux (его private data не читается другими приложениями)
   в общедоступную папку Download или загрузить GGUF туда заново.
2. Раздел «Модели» → «Добавить GGUF с телефона» → выбрать файл.
3. Дождаться копирования в private storage приложения. Нужно свободное место
   дополнительно примерно равное размеру выбранного файла.
4. Нажать «Запустить», дождаться загрузки, перейти в «Чат».
5. Для проверки написать «Ответь одним словом: готово».

CPU-only, Android ARM64, 2048 context, 512 max generation, 4 threads.
Возможность отправлять сообщения в фоновые сервисы и анализировать фото пока
не реализована. Векторные базы, длительная память и агенты не активированы.

**Ограничения тестовой версии:** история сохраняется только пока открыт чат;
после перезапуска приложение снова требует ручной загрузки модели в RAM.
Файлы GGUF сохраняются в private storage; при удалении приложения они удаляются.

Пока релиз подписывается debug key GitHub runner: разные сборки могут быть
несовместимы при установке поверх предыдущей. Позже нужно настроить
постоянную release-подпись и GitHub Secrets.

Внимание: код рассчитан на конкретный upstream commit `f2f667b02dc76d675395ae3b14546c8108d26387`.
Для перехода на новые версии нужно согласованно обновлять JNI и pin.
Первую CI сборку надо проверить: здесь нет Android SDK/Flutter, поэтому
невозможно утверждать, что APK уже собран успешно.
