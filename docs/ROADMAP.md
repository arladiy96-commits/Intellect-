# Очерёдность разработки

1. Каркас Flutter/Android и ручная сборка APK в GitHub Releases.
2. Нативный движок llama.cpp без Termux; загрузка моделей GGUF из памяти телефона.
3. Настоящий чат, потоковая генерация, история, переключение моделей.
4. Память, база знаний, каталог инструментов.
5. Внутренние агенты и многошаговые задачи с проверками.
6. Android-агент: AccessibilityService, MediaProjection, права, журнал и подтверждения.
7. Защищённый удалённый доступ с явным согласием владельца.

Примечание: Android может ограничивать длительную фоновую работу. Проверим на устройстве.
