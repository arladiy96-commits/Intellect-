# Мой ИИ — архитектура

- `lib/src/core/ai` — абстракция движка и будущая нативная интеграция llama.cpp.
- `lib/src/core/agents` — определения агентов, реестр инструментов, разрешения.
- `lib/src/core/android_control` — будущий Android AccessibilityService / MediaProjection через Kotlin.
- `lib/src/core/memory` — сохранение чатов и память.
- `lib/src/features` — экраны Flutter: чат, агенты, модели, настройки.
- `assets/models` — место для локальных моделей на устройстве (файлы GGUF НЕ коммитить).

Bootstrap создаёт компилируемый каркас интерфейса, НЕ функциональный ИИ.
Следующий этап: нативная llama.cpp-интеграция с GGUF, сохранение истории, выбор модели.
Android-управление — только с явными разрешениями, подтверждениями и журналом действий.
