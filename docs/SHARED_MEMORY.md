# Бабуин — общая долговременная память (этап 1)

## Назначение

Память хранится локально в `memory.v1.json` внутри каталога приложения Android.
Она **не относится к конкретному чату**. Смена диалога, закрытие приложения и
перезапуск не удаляют данные. Старые записи формата `{id, text}` читаются без
миграции. Движок llama.cpp, модели GGUF и система обновлений не изменяются.

## Возможности

- Пятая вкладка «Память» (поиск, категории, закрепление, изменение, удаление).
- Нажатие и удерживание сообщения в чате — сохранить в общую память.
- Команды «Запомни, что...», «Запиши в память: ...» или «Сохрани в память: ...»
  сохраняются автоматически как явно указанные пользователем сведения.
- Дедупликация дословно совпадающих автоматических записей.
- Прежде чем отвечать, Qwen получает до шести небольших записей из общей
  памяти, отсортированных с учётом слов в текущем вопросе и закрепления.
- Всё работает без сетевого доступа. Никакого дополнительного ИИ-запроса
  для сохранения явных команд нет, поэтому скорость генерации почти не меняется.

## Ограничения этапа 1

- Без явной команды «Запомни» произвольные сведения пока автоматически **не**
  извлекаются: маленькая 4B-модель может ошибиться и сохранить ложную память.
  Следующий этап — предложенные ИИ факты с подтверждением пользователя.
- Текст воспоминания ограничен 300 символами; старые длинные записи в памяти
  сохраняются, но в контекст передаётся сокращённая версия.
- Лимит передаваемой памяти — примерно 650 символов плюс системные инструкции,
  а не вся база. При 2048 токенах длинные беседы по-прежнему требуют обрезки
  старых сообщений.
- Удаление данных приложения Android удалит память вместе с GGUF. Перед
  первой установкой APK с новым сертификатом нужен отдельный план резервного
  копирования. Обновления с той же подписью сохраняют данные.

## Проверка после сборки

1. В «Память» добавь запись «Любимый язык ответов — русский».
2. Создай новый чат и спроси, какой язык предпочитаешь.
3. Отправь «Запомни, что мой проект называется Бабуин».
4. Перейди во вкладку «Память» и проверь появление записи.
5. Закрой и открой приложение, затем создай новый чат.
6. Проверь, что оба воспоминания на месте. Попробуй изменить/удалить запись.
7. Проверь «Настройки → Обновления» — экран должен остаться рабочим.

## Файлы обновления

- `lib/src/core/memory/conversation_repository.dart` — расширение формата
  записей и выбор релевантных воспоминаний (с обратной совместимостью)
- `lib/src/core/memory/shared_memory_store.dart` — единое последовательное
  хранилище заметок, доступное всем чатам
- `lib/src/features/memory/memory_screen.dart` — новый отдельный раздел
- `lib/src/features/chat/chat_screen.dart` — подключение общей памяти
- `lib/src/app.dart` — пятая вкладка «Память»
- `test/shared_memory_test.dart` — тесты формата, явных команд и контекста

Другие файлы менять не нужно. Bootstrap повторно не запускать.
