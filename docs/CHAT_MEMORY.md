# Мой ИИ: диалоги и память (первая версия)

- Все чаты сохраняются локально как JSON в Application Support / chat_data.
- Кнопка «История» открывает чаты, их можно открыть, переименовать или удалить.
- «Новый диалог» начинает пустую беседу и не удаляет прежние.
- Кнопка «Память ИИ» хранит заметки пользователя отдельно от чатов.
  Долгое нажатие на сообщение позволяет сохранить его в память.
- Заметки учитываются при последующих запросах (до 700 символов);
  они не извлекаются из диалогов автоматически.
- Все сообщения остаются в истории на диске. Для локальной модели Flutter
  передаёт не более 48 последних сообщений, а JNI точно измеряет токены
  и убирает наиболее старые реплики из текущего запроса, если места мало.
- Ограничение контекста GGUF остаётся 2048 токенов, maxTokens = 512.
- Автоматическое суммирование/поиск по старым перепискам, семантическая
  память и настройки контекста будут отдельным этапом.
- База хранится в личной папке приложения и обычно сохраняется при
  установке обновлений с той же подписью. Удаление приложения или очистка
  его данных удалит историю и импортированные модели.

## Проверка на телефоне

1. Запусти модель в «Модели» и создай чат.
2. Напиши два вопроса подряд с отсылкой к первому вопросу.
3. Создай второй чат, вернись в первый через «Историю».
4. Сверни и снова открой приложение; проверь историю.
5. Сохрани полезное сообщение долгим нажатием, открой новый чат,
   спроси то, что связано с сохранённой заметкой.
6. Проверь длинный диалог: переписка должна сохраняться, а сервер
   не должен аварийно завершаться при исчерпании контекста.
