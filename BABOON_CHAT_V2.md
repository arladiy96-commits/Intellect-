# Бабуин — чат v2 (архитектурный этап)

## Сделано

- SQLite `chat_data/baboon_chats.v2.sqlite`: `threads`, `messages`, `drafts`, `metadata`.
- Первый запуск автоматически и атомарно переносит `conversations.v1.json`
  (или `.bak` при повреждённом основном файле). Старый JSON **не удаляется**.
- Память по-прежнему находится в `memory.v1.json`, GGUF и настройки не затронуты.
- В сообщениях сохраняются ID, роль, текст, тип, время, модель, статус.
- `ChatSessionController` отделён от виджета. Генерация продолжается при
  переходах по другим вкладкам/диалогам, пока процесс Android жив.
- Запросы в очереди выполняются по одному; отправленные сообщения записываются
  в базу *до* вызова внешней модели. Текст генерации сохраняется периодически.
- После смерти процесса незаконченная генерация помечается «Прервано» — без
  автоматического повторного платного запроса. Очередь неотправленных запросов
  восстанавливается и продолжается, когда модель доступна.
- Черновики чатов сохраняются; можно печатать следующий запрос во время ответа.
- Исправлено навязчивое автолистание: оно включено, пока пользователь внизу.

## Инварианты

1. SQLite-транзакция записи потока не удаляет старый JSON.
2. Только один запрос к движку выполняется одновременно во всём приложении.
3. Статус `generating` после перезапуска становится `interrupted`.
4. Прерванный ответ сохраняет частично полученный текст; повтор — только по кнопке.
5. При ошибке миграции пользователь видит ошибку; пустая база не подменяет данные.

## Проверка на реальном устройстве

1. Сделать резервную копию данных до обновления. Установить подписанный APK
   поверх действующей версии, не удаляя приложение.
2. Проверить старые чаты, общую память, загрузку GGUF, облачные ключи.
3. Отправить несколько вопросов; открыть другой чат во время ответа;
   вернуться и проверить отсутствие потери текста и очередь.
4. Прервать ответ, свернуть приложение, принудительно остановить процесс и
   заново открыть чат. Проверить метку «Прервано» и кнопку «Повторить».
5. Сохранить черновик, переключить чат, вернуться и проверить текст.

## Что отдельно и позже

Markdown-рендерер, редактор прошлых сообщений, поиск по истории,
мультимодальные вложения и агентные действия. Они будут добавляться к уже
выделенному контроллеру и схеме данных.
